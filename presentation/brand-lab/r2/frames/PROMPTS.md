# Daybreak style-frame prompts

These are AI-generated mood frames for art-direction review, not screenshots of the real product or finished animation. All maps, routes and UI are synthetic concepts.

Tool: built-in `image_gen.imagegen`. Model: not reported by the tool response. No model name or version was exposed, so the newest model cannot be independently confirmed. The tool exposes no model selector, size parameter or quality parameter; the prompts request the newest available model and the largest native 16:9 output, ideally 3840 x 2160. Actual output dimensions and any reported model will be recorded below after generation.

## Delivery and verification

- Generated with eight built-in image calls, one per frame. No external image API was used.
- All eight source outputs were 1672 x 941 pixels. The tool did not honour the requested 3840 x 2160 size and exposes no explicit size control. These are the native dimensions returned, not a verified maximum capability.
- Final PNGs are 1664 x 936, exactly 16:9, using a lossless centre crop of only 8 horizontal and 5 vertical pixels in total. No upscaling, repainting or colour adjustments.
- The tool automatically caches originals outside the requested folder. All authored deliverables and file-processing outputs were written only into the requested frames folder; cached originals were left untouched.
- Contact sheet: two rows by four columns, labels outside the frames, assembled with Python/Pillow.
- Visually inspected all eight frames: no visible text, letters, numbers or logos; both map frames have one shared base and exactly three routes, with 4/3/4 stops respectively, satisfying the requested 3–4 stops per route even though the prompts requested three.
- The console is an intentionally text-free synthetic concept, not the real Daybreak UI. These stills establish art direction; they do not demonstrate motion, transitions or production-ready 3D geometry.

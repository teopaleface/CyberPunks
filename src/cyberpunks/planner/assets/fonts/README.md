# Fonturi pentru ordinele de lucru (PDF)

- Font: Noto Sans (Regular și Bold), versiunea 2.015
- Sursa: https://github.com/notofonts/notofonts.github.io (fonts/NotoSans/full/ttf)
- Licența: SIL Open Font License 1.1 (vezi `OFL.txt`)
- Modificare: fișierele sunt reduse (subset) la alfabetul latin, Latin-1 și Latin extins A/B, cu punctuație uzuală, ca să fie mici (~44 KB fiecare). Conțin ă â î ș Ș ț Ț (U+0219, U+0218, U+021B, U+021A). Nu conțin săgeata U+2192.

# Cinci prompturi pentru implementarea agentului

Aceasta este împărțirea acceptată de Teo. Înlocuiește pachetul inițial de 19 prompturi; fișierele vechi rămân doar referință și nu se lansează separat.

1. [Analiza cozii și deciziile agentului](compact/01-analiza-si-decizii.md).
2. [Sarcini persistente, confirmări și recuperare](compact/02-persistenta-si-confirmari.md).
3. [Rapoarte vizuale și WhatsApp](compact/03-rapoarte-si-whatsapp.md).
4. [Interfața și legătura cu telefonul](compact/04-interfata-si-telefon.md).
5. [Integrare și verificare finală](compact/05-integrare-si-verificare.md).

Coordonatorul fixează întâi contractele, apoi primele trei sarcini rulează simultan. A patra începe la primul loc liber. Integrarea se face pe parcurs; verificarea completă încheie execuția. Manifestul activ este [compact/manifest.json](compact/manifest.json).

Stare: implementare locală realizată și verificată. Serviciile de demo nu au fost repornite și nu s-a făcut deploy. Probele de pe telefon și livrarea reală prin Meta rămân distincte. Vezi [acceptanța locală](../operations/AGENTIC-ACCEPTANCE.md).
